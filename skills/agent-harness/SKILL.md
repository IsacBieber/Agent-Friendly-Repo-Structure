# Agent Harness

收到「启动验收流程」「用验收架构」「继续验收任务」「查看验收进度」或显式调用本 Skill 时，读 [工作流](references/workflow.md)。

1. 以用户指定的项目或目录为任务范围，否则使用当前项目或可写工作目录。先遵循项目约定。
2. 启动时把用户的要求和逐项验收条件写入任务记录，目标明确后立即推进。继续任务时，从最新一轮的文件和当前候选确定下一步。任务无法唯一定位且选择会改变工作对象时，请用户指定。
3. 查看进度时只读任务文件并报告当前阶段、最近证据和下一步。若触发时未给任务目标且要开始新任务，先获取目标。
4. 有可重复测试时，按 [本地验证](references/verification.md) 在开工前冻结判据，交付前运行并保存机器结果。继续时先核验证据对应的候选。结论要落到实际交付物和可复核的证据上。
5. 交付时给出任务 ID、验收页及待人工决定的事项。若用户明确要求续接一个正式协议工作区，沿用该工作区的 `ENGINE.md` 和 2_tools 规则。外部发送、部署或发布按用户为该动作授权的范围执行。
