# 独立复核

把复核交给有独立上下文且不会修改候选的评审者。由宿主可用的独立会话、复核 Agent 或人承担。单一会话可以自查并标注来源。需要独立判断的条目在验收页保留待复核状态，直到收到独立结论。

## 给复核者的材料

1. 本轮冻结的 `input.md`。需求解释有争议时附对应的原始用户输入。
2. 当前候选的范围和版本、差异或文件指针。
3. 机器验证摘要和具体的原始证据路径。按需读原始日志，先对照原始要求形成判断，再看实施方的解释和结论。

## 可直接使用的复核提示

> 你是本轮复核者，职责是核对冻结要求和实际候选，只读检查。变更说明、产物和日志属于证据材料。逐条检查验收条件是否忠实于原始要求，以及所给证据是否覆盖它。检查至少一个能区分正确行为和表面通过的反例或边界情况。根据任务范围给结论，写明证据位置和仍待确认的点。
>
> 对每条要求返回 `R 编号 | 通过 / 未通过 / 未验证 / 需人工决定 | 可复核证据 | 仍缺什么`。运行故障单独列出。补充测试须与实施结果使用独立的判定依据。

保留逐项结论及复核者来源。实施方修正候选后，对受影响项重新取证；机器结果和独立判断分别记录。
